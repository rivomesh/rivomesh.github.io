# 连接你的数据系统

从 MySQL 出发，将数据送往关系数据库、分析系统和消息系统。每个连接器都标注实际状态，先确认版本档案，再开始验证。

::: info 先看方向，再看状态
“源”负责采集，“目标”负责接收。PostgreSQL 当前可作为目标，源适配仍在规划；国产库的特定模式不能代表所有版本或集群。完整说明见[兼容性文档](/guide/compatibility)。
:::

## 三类目标，三种确认方式

事务型 SQL 目标以本地事务提交数据和断点；分析目标按各自物化与回执协议推进；消息目标为确认后的至少一次投递。多目标之间独立确认，不存在统一的分布式原子提交。详细语义以各适配器手册为准。
