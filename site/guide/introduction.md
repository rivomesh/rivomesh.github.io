# 什么是 RivoMesh？

RivoMesh 是一个基于 Java 的数据同步项目。它把业务数据库中已有的数据和后续变化，持续传递到选定的目标系统，并提供 Web 控制台管理任务。

例如，你有一个 MySQL 业务系统，需要把数据同步到 PostgreSQL 测试库，或分发到分析系统。RivoMesh 先读取现有数据，再跟踪 MySQL 的变更日志，把新增、修改和删除送往目标。目标的兼容性与一致性取决于所选适配器。

## 用业务语言理解几个概念

| 概念 | 可以这样理解 |
| --- | --- |
| 数据源 | 业务数据从哪里来；当前可用采集源为 MySQL |
| 目标 | 数据要送到哪里；可以是数据库、分析系统或消息系统 |
| 全量同步 | 先把已有的数据传过去 |
| 增量同步 / CDC | 持续捕获后续新增、修改和删除 |
| 任务 / Pipeline | 一条确定的数据流，包含源、库映射、目标和日志 |
| 日志 / Journal | 保存同步事件与进度，便于重启恢复；需要持久磁盘或外部事务库 |
| 断点 | 已安全处理到的位置；不是简单的行数统计 |
| 校验与修复 | 在受支持的共同校验点比较数据，审阅计划后修复目标差异 |

## 为什么值得试用

**先用界面跑通流程。** 可以通过中英文向导建立任务、检查配置、查看全量与积压状态。常见任务操作有清晰入口，复杂配置仍可用 YAML 管理。

**一份源数据，按需分发。** V3 显式配置多 database 与多个目标，每个目标独立确认与恢复。不同目标之间不构成一个分布式原子事务。

**遇到错误，保留排查线索。** 连接类暂时错误按策略重试，确定性 SQL 错误暂停相关目标，修复后重试原事务。不会通过自动跳过数据制造“正常运行”的假象。

**部署方式可选。** 现有 Linux 服务、Docker Compose、Helm 与 Kubernetes 清单可供试用，实际集群和性能仍需按环境验证。
