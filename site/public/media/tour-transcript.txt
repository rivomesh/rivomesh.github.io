1. 认识 RivoMesh
欢迎认识 RivoMesh。它是一个基于 Java 的数据同步项目，从 MySQL 出发，将已有数据和后续变化送到数据库、分析系统或消息系统。下面用五个步骤，了解怎样开始使用。

2. 准备连接与配置
首先，准备 MySQL 测试源和一个独立的空目标。启动控制台后，通过任务向导填写源地址、数据库、目标映射和日志。源库需要满足 GTID 和完整行镜像要求，具体权限请由数据库管理员核对。

3. 创建任务，观察进度
保存配置后，先执行检查，再启动任务。控制台展示同步阶段、积压和目标状态。请在测试库验证新增、修改、删除与重启续传。这里展示的是真实开发预览，停止状态和数字不是运行效果的承诺。

4. 校验数据，按计划恢复
遇到目标错误，先修复原因，再重试原事务。受支持的 MySQL 和 PostgreSQL 目标，还可以在共同校验点比较数据，由管理员审阅修复计划后执行。修复不会自动恢复同步，也不表示业务切换已经完成。

5. 从一个小试点开始
当前是发布前版本。建议先跑通一条小链路，记录配置和验证结果。网站提供中英文文档、连接器状态和 SDD 路线图。PostgreSQL 和 Oracle 源仍在规划，未来能力以实际实现和验收为准。
