# 一起建设 RivoMesh

RivoMesh 正在准备首次公开发布。欢迎从文档、可复现问题、连接器验证和测试用例开始参与，让项目能够在真实环境中持续改进。

## 从小处开始贡献

| 方向 | 具体可以做什么 |
| --- | --- |
| 文档 | 改正操作步骤、补充术语解释、中英文校对、检查链接 |
| 使用反馈 | 记录安装、连接检查、首次同步和恢复过程中的阻碍 |
| 兼容性 | 提供确切数据库版本、模式、驱动、JDK 及可复现实验 |
| 开发 | 按需求 ID 提交设计、实现和正反向/故障恢复验证 |
| 视觉与体验 | 改善官网、图标、控制台可访问性和首次使用流程 |

## 提交问题时提供什么

写清楚使用版本、数据库产品/确切版本、JDK、日志模式、部署方式、复现步骤、预期与实际结果。附上已脱敏配置和错误摘要；保留完整证据在你自己的安全环境中，不要把凭据或业务数据上传到公开 Issue。

## 按 SDD 追踪贡献

先在[路线图](/roadmap)找到需求 ID，再核对[规格](/reference/sdd/001-control-recovery-compatibility/spec)、[任务](/reference/sdd/001-control-recovery-compatibility/tasks)与[验收条件](/reference/sdd/001-control-recovery-compatibility/acceptance)。提交变更时注明需求 ID、实现边界、迁移影响、中英文文档及候选包证据。通过构建不等于通过完整数据库或集群验收。

当前没有公开邮件组、聊天群、商业支持承诺或真实用户案例；后续建立相应渠道后会在这里更新。
