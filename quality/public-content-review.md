# 对外内容与产品路线图整理

日期：2026-11-17。范围为官网文案、内容层级和导航；保留 VitePress、现有组件、文档路由、连接器事实及原始产品媒体。

## 调整

- 中英文品牌与导览页删除素材制作过程、缺少截图及“未伪造界面”等内部交付表述，直接提供产品媒体和操作指南。
- 首页“开发预览”由五处收敛为版本状态与图库来源两处。首屏继续明确 MySQL 采集源；未来源数据库统一引导到路线图。连接器方向、实验性状态、消息至少一次投递及多节点不自动跨 Agent 接管的限制保留。
- 多节点模块先说明节点、任务、账号及管理/执行部署方式，再通过既有展开区域提供部署条件。底部改为明确的参与与贡献入口。
- 产品路线图先展示当前可用能力、正在完善及后续计划。当前能力标题复用首页数据；演进方向通过需求 ID 读取同一份需求清单的状态，缺失 ID 会阻止构建。未承诺发行日期。
- 原有 48 条需求、状态、优先级、差距、依赖、验收条件、搜索及筛选完整保留在默认关闭的原生 details 中。
- 产品路线图归入“开始使用”，可由默认的用户文档搜索找到。中英文路由和文档侧栏滚动、定位、折叠状态机制保留。
- 社区与下载页改为直接说明反馈、贡献、构建和环境要求，详细开发协作流程按需展开，保留源码、发布与许可入口。
- 播放器标题强调语言和字幕，在播放器下方保留清楚的 OpenAI 合成旁白说明。两种语言的原视频、字幕、封面和原始截图均未改动；任务向导截图旁增加 V3 配置格式说明。
