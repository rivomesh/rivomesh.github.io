# 英文产品截图补全

日期：2026-11-17。英文首页 Hero、产品截图区和英文产品导览页均改用真实英文控制台截图；中文页面保留原来的中文截图。中英文视频资源没有改动。

## 素材来源

从本机已有产品 JAR 的隔离副本启动 localhost 开发预览，以 Chrome 无头浏览器和 `en-US` 语言打开产品原生英文界面，通过正常登录及页面控件采集。没有修改产品源码、注入译文、替换接口响应或生成虚构界面。

示例 `sales-replication` 为已加载、未初始化的停止任务，没有启动同步或执行数据库检查。任务向导仅填写未提交的草稿。连接器目录显示产品当时实际返回的能力说明；截图是开发预览，不代替官网维护的兼容性矩阵或实时运行证据。产品语言切换按钮中的“中文”为真实目标语言标签。

- `website/public/media/console-overview-en.png`：任务列表、停止状态及操作入口。
- `website/public/media/task-wizard-en.png`：完整的英文源配置步骤和继续按钮。
- `website/public/media/connector-catalog-en.png`：英文连接器能力目录。
- 每张原图为 1800×912；同时提供 `-900.webp`、`-1800.webp` 两个响应式版本，总共九个新图片文件。
- 采集时间、JAR SHA-256、原图 SHA-256 及实际页面标题见 [来源记录](english-screenshots-source.json)。原始截图只经过无损 PNG 编码，WebP 通过既有 Sharp 脚本生成。

共享的 `ScreenshotPreview` 按页面语言选择 PNG、WebP 和弹窗原图。英文替代文字、来源说明、品牌页及 README 同步更新。`npm run check` 检查两种语言的全部原图与派生图尺寸；构建检查额外验证中英文 Hero 的图片语言。

## 验证

- `npm run check`：152 篇文档、1049 个本地链接、品牌及中英文视频校验通过，新增截图存在性和尺寸检查通过。
- `npm test`：26 项通过，覆盖三个英文图库视图的 PNG/WebP 路径，以及英文大图弹窗；保留中文切换、键盘关闭与焦点恢复测试。
- `npm run build`：VitePress 构建通过，17526 个发布导航/资源引用、152 篇文档侧栏、164 页 SEO/语言元数据检查通过。
- Playwright + 本机 Chrome：中英文首页、导览页，320 / 375 / 390 / 768 / 1024 / 1440 / 1920 CSS px，深浅两种主题，共 56 组检查通过；页面没有水平溢出，图片解码成功。390 / 1440 px 另检查三个图库切换、原图弹窗及 Escape 关闭。
- 实际查看三张英文产品原图、1440 px 浅色英文首页及 390 px 深色英文首页截图，没有发现素材错配或明显重叠。
- 英文导览实际加载独立英文 MP4，时长约 107 秒，默认英文字幕处于 showing 状态；没有改写配音或视频。
- 浏览器检查没有页面 JavaScript 异常；详细结果见 [浏览器记录](english-screenshots-browser.json)。

以上为桌面 Chrome 的视口模拟，未做真实手机设备、Safari 重复检查、Lighthouse 性能评分或主观语音听感评分。
