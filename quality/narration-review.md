# OpenAI 产品导览配音更新

日期：2026-11-17。

## 交付

- 五章中文旁白由原来的 macOS Tingting 系统语音替换为 OpenAI `gpt-realtime-2.1` / `marin`。指令要求自然普通话、适中语速、连贯停顿和技术名称读法，正文保持原稿。
- 保留原有五幅画面内容、真实开发截图、封面和中英文文字稿。依据新的朗读长度重新安排静态画面停留；不通过加速音频压回旧时长。淡入淡出仍为 0.3 秒。
- 视频由约 102 秒变为 116 秒，章节起点为 00:00、00:21、00:42、01:06、01:31。输出 1280×720 / H.264 / AAC、48 kHz 单声道，2,565,740 字节。
- 中英文各 18 条字幕共享新的语音时间点。保留原有权威文字，词级时间戳用于对齐，不直接将转写中的同音字替换进字幕。
- 首页与中英文导览显示 AI 合成旁白；播放器、字幕及组件下载链接携带实际 MP4 SHA-256 派生的版本号，避免继续命中旧声音缓存。

生成来源及每章数据见 `website/public/media/voice-report.json`；播放器版本见 `website/.vitepress/data/tour-media.json`。

## 工具与复现

`npm run voice:plan` 不调用 API；`npm run voice:sample` 生成第一章；`npm run video:preview` 输出预览；`npm run video:generate` 应用完整视频、字幕、章节、版本与来源记录。讲稿来源仍为已提交的 `transcript.txt`，英文字幕来源于原有英文文稿。

凭据从环境变量或被 Git 忽略的 `.env.local` 读取；音频缓存、原媒体备份及预览仅放在被忽略的 `.rivomesh-voice.local/`。不同文本、指令、音色和模型对应不同缓存指纹；本轮最后一次完整生成确认五章全部复用缓存，未再次调用 API。失败不自动重试付费生成。普通 `check`、测试、构建和 CI 不调用 OpenAI，不需要 FFmpeg、macOS `say` 或凭据。

使用已有依赖树中的 `ws` 8.23.0、`https-proxy-agent` 7.0.6 作为显式开发依赖，没有增加浏览器运行时依赖。技术说明及命令见 README。

## 验证边界

本环境无法对音色作人耳听觉验收，未宣称完成主观听感评分。已提供真实生成音频并验证内容、媒体结构、时间轴、字幕和网页播放；最终语气偏好可通过正式导览试听判断。

`whisper-1` 的专门词级时间戳能力已公告于 2027-02-26 关闭，README 已记录离线对齐工具的后续迁移事项。语音生成采用当前 Realtime 流程，没有新接入已弃用的 Speech API。普通网站运行不受离线生成服务变化影响。
