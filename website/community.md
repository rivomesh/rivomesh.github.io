## 从哪里开始

| 方向 | 可以贡献的内容 |
| --- | --- |
| 文档 | 改正操作步骤、补充术语、双语校对、检查链接 |
| 兼容性 | 提供确切版本、模式、驱动、JDK、负载与可复现实验 |
| 开发 | 修复问题、完善连接器、改进同步与恢复流程，并补充测试 |
| 体验 | 改进控制台、任务向导、错误解释与可访问性 |
| 使用反馈 | 记录从部署到首次同步、故障恢复的实际阻碍 |

## 反馈问题时准备什么

说明版本、数据库确切产品与模式、JDK、日志和部署方式、复现步骤、预期及实际结果。附上脱敏后的配置和错误摘要；凭据、管理令牌与业务原始值不要提交到公开 Issue。

## 提交改进

小的修正可以直接提交 Pull Request；涉及新连接器、恢复机制或部署方式的变更，建议先通过 Issue 讨论使用场景和范围。说明修改后的行为、测试方式和兼容性影响，并更新对应文档。

在[产品路线图](/docs/zh/start/roadmap.html)查看当前能力和待验证场景。涉及现有问题时请关联对应 Issue，提供测试环境、恢复行为与迁移影响。
