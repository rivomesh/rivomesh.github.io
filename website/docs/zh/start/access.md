# 账号与使用权限

建议为使用者分配独立账号，按工作职责授权。业务查看人员通常只需要读取任务状态；管理配置和数据修复应交给相应管理员。

## 选择角色

| 角色 | 典型职责 |
| --- | --- |
| VIEWER 只读用户 | 查看授权任务、运行状态和允许读取的报告摘要 |
| OPERATOR 操作员 | 在授权范围内进行日常任务操作 |
| ADMIN 管理员 | 管理配置、账号、授权，以及校验与修复等管理操作 |

实际入口同时受角色和任务授权限制。看不到某条任务或操作按钮时，应先请管理员检查授权。

## 管理账号和会话

管理员按[账号管理说明](../reference/account-management)创建和维护账号，并按[任务授权说明](../reference/task-authorization)限制可访问任务。账号停用、密码或会话调整后，应核对后续访问是否按预期生效。

远程使用时，由部署人员配置 HTTPS 和浏览器会话选项。多节点需要统一访问身份时，按[共享账号、会话与审计](../reference/shared-access)部署，避免把不同节点各自的本机配置误认为已经共享。

## 使用组织账号登录

共享控制部署可接入一个 OpenID Connect 提供商。所有登录 Controller 使用同一 HTTPS 地址，配置授权码流程与 PKCE S256。管理员将该客户端收到的区分大小写的 `sub` 绑定到现有 RivoMesh 账号；角色、任务和节点权限仍由本地目录决定。

绑定、替换或撤销身份后，旧浏览器会话会在各入口失效。要立即停止已有访问，请在 RivoMesh 中撤销绑定或停用本地账号。令牌登录与 Bearer API 仍可使用。配置、证书和故障排查见[组织账号登录手册](../reference/oidc-login)。

## 查询操作记录

遇到任务被停止、配置被修改或校验失败时，可先按任务和时间查询操作记录。需要更完整追踪时，管理员查阅[安全审计说明](../reference/security-audit)。

管理令牌、密码和业务原始值应保存在受控环境，不能提交到公开问题或网站反馈中。
