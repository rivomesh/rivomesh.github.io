# RivoMesh 使用指南

把源库中已有的数据和后续新增、修改、删除持续同步到信创数据库、其他关系数据库、分析系统或消息队列。你可以通过 Web 控制台配置和管理整条同步任务。

<UsagePaths />

## 第一次使用

如果环境还没有准备好，从[安装与启动](install)开始。如果你已经拿到访问地址和账号，直接按[创建同步任务](create-task)完成第一条链路。

想先了解界面，可以观看[中文产品讲解](/tour.html)，或按[快速开始](quick-start)完成一次小规模测试。

## 使用前的几个约定

首次试用请使用测试来源和独立空目标。先核对字段值、新增、修改、删除和重启恢复，再扩大范围。数据库的日志、权限和生产影响应由数据库管理员确认。

每个目标有自己的确认进度和使用条件。查找具体参数时，展开“详细配置参考”；架构、验证记录和贡献资料在独立的[项目资料](/project.html)入口。
