# 信创数据库适配与改造

RivoMesh 可在信创改造过程中，将 MySQL 业务数据同步到国产数据库测试环境，持续核对历史数据和后续变化，为数据库适配、并行验证及切换准备提供数据链路。

当前已实现的采集源是 MySQL。下表介绍的是**同步目标**；支持写入某种数据库，不表示已经支持从该数据库采集。PostgreSQL、Oracle 源列在[源端扩展计划](#源端扩展计划)中。

## 选择适配目标

| 目标数据库 | 当前范围 | 使用说明 |
| --- | --- | --- |
| openGauss / GaussDB | openGauss 7.0.0-RC3 部分验证；商业 GaussDB、分布式形态待独立验证 | [索引与约束策略](../reference/gaussdb-index-policy) |
| 达梦 DM | DM8.1.4.80 指定 UTF8 模式，实验性；已有全量、增量及故障恢复记录 | [达梦连接说明](../reference/dm-v3) |
| 金仓 Kingbase | V9 指定 PG/UTF8 模式，实验性；已有全量、增量及故障恢复记录 | [金仓连接说明](../reference/kingbase-v3) |
| GBase 8c | V6 S1.3.0B19 指定 PG/UTF8 模式，实验性；8a、8s 仍在规划 | [GBase 8c 连接说明](../reference/gbase8c-v3) |
| OceanBase | MySQL 兼容业务租户，实验性；已有原生事务及部分同步记录，完整联合恢复尚未通过 | [OceanBase 连接说明](../reference/oceanbase-v3) |

这些状态对应指定版本与模式。驱动、编码、数据库集群和安全配置需要按实际环境验证；本项目的适配记录不等同于厂商认证。完整目录见[数据源与同步目标](connectors)。

## 如何开展信创改造验证

1. **确定范围**：选取代表性库表，记录数据库版本、兼容模式、驱动、编码、业务维护窗口和同步用途。
2. **建立独立验证环境**：保留原业务库，准备空目标表或空 schema，目标仅由同步任务写入。按照[创建同步任务](create-task)建立数据链路。
3. **核对数据语义**：验证中文、大小写、空字符串与 NULL、时间精度、带符号时长、金额精度、JSON、无主键重复行和生成列。
4. **审阅对象差异**：核对类型映射、主键、唯一约束与索引。降级为普通索引的业务约束，在应用接管前需要单独恢复和验证。
5. **演练恢复**：验证目标停机、网络中断、工作进程重启和 SQL 错误修复；多节点部署同时核对日志、断点与接管条件。
6. **制定切换方案**：单独评估应用 SQL、存储过程、权限、性能、停写窗口和回退。同步完成不能代替应用兼容性验收。

管理界面的自动逐行校验与修复，目前首批真实验证目标仍为 MySQL / PostgreSQL。国产数据库的业务值核对需按各连接器手册和独立比对流程开展，不能直接套用该修复范围。

## 多节点与持续同步

信创适配环境可以按需部署多个服务节点，观察各节点状态，并在启用共享访问后统一账号、会话和审计。跨主机续传需要外部事务日志及正确的任务身份；可选固定执行节点全局控制已接入，管理与 Agent 分离已有首批验收，自动跨 Agent 接管和其他部署组合需另行验证。详见[多节点部署与恢复](multi-node)。

## 源端扩展计划

RivoMesh 的源适配接口将对象发现、全量读取、事务变更与断点恢复分开，便于后续接入不同数据库的日志和位置模型。

| 采集源 | 当前状态 |
| --- | --- |
| MySQL | 已实现；按版本核对全量、增量及恢复范围 |
| PostgreSQL | 规划中，当前不能作为可运行采集源选择 |
| Oracle | 规划中，当前不能作为可运行采集源选择 |
| 其他数据库 | 可通过源适配接口继续扩展；尚无已承诺的产品列表或交付日期 |

后续国产数据库源也需要独立实现、验证并登记。目标端的 JDBC 兼容性不能替代源端 CDC 能力。进展见[项目路线图](roadmap)及[平台设计](../reference/platform-design)。
