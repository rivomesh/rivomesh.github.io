# SDD任务清单

RM-SDD-001 · 2026-11-16

每项任务完成必须包括设计/实现、正反向与中断恢复测试、双语文档和候选包证据。已验收节点目录及5项会话任务，余42项保持未完成；见[会话证据](/docs/zh/evidence/2026-11-16-browser-sessions.html)。依赖是实施顺序，不表示必须等待所有厂商档案才能开发公共框架。

## 多节点统一控制

- [x] T-CP-01 · 统一节点注册与状态 · P0 · 依赖：无
  交付：部署两个节点后，任一管理入口均显示相同节点ID、角色、版本/JDK/架构、容量、心跳时间和任务归属；失联显示过期/未知，不能伪装成健康。
  验收：AC-CP-01
- [ ] T-CP-02 · 全局任务、配置与操作权威状态 · P0 · 依赖：CP-01
  交付：同一集群中从A创建/修改任务后B读到同一全局修订；全局taskId唯一，独立任务与源配置仍隔离；单机模式保留可运行配置。
  验收：AC-CP-02
- [ ] T-CP-03 · 跨节点持久命令路由 · P0 · 依赖：CP-02
  交付：任一入口可控制B的任务：创建、检查、启停、暂停/恢复、重试、校验/修复；命令含全局请求ID/修订/owner代次，重复投递只生效一次，202仅表示接受，返回已执行/拒绝/未知结果。
  验收：AC-CP-03
- [ ] T-CP-04 · 故障接管、隔离与资源调度 · P0 · 依赖：CP-03, JV-01, LG-05
  交付：节点断电/网络分区/旧节点恢复时同一任务无双写；未确认停机可标记未知并隔离；按JDK、连接器、存储可达性和配额调度；排空迁移保留断点。
  验收：AC-CP-04
- [ ] T-CP-05 · 共享权限、审计和密钥引用 · P0 · 依赖：CP-02
  交付：从A撤销权限后B拒绝新命令；同一远端操作可按请求ID/任务/节点/计划追踪；界面不返回密钥，节点仅获得授权任务必需的密钥引用。
  验收：AC-CP-05
- [ ] T-CP-06 · 全局日志、指标与诊断界面 · P1 · 依赖：CP-01, CP-03, CP-05
  交付：界面按节点/任务/目标过滤状态、延迟、积压、日志和错误；注明采集时间及失联范围；远端日志分页/限流且不泄露业务值或凭据。
  验收：AC-CP-06
- [ ] T-CP-07 · 控制面HA及控制/数据面解耦 · P0 · 依赖：CP-03, CP-05, SE-04
  交付：管理实例故障后其他入口可继续查询/控制；接收但未完成的命令可恢复；按明确策略已有Worker可继续安全同步；仅部署多个replica或共享目录不能算通过。
  验收：AC-CP-07
## 登录状态保持

- [x] T-SE-01 · 刷新后恢复登录态 · P0 · 依赖：无
  交付：登录后刷新、重新打开同一站点页面可恢复未过期会话和原权限，不需再次输入令牌；过期则回到登录页且不误发操作。
  验收：AC-SE-01
- [x] T-SE-02 · 会话期限、退出和撤销 · P0 · 依赖：SE-01
  交付：可配置空闲/绝对有效期；退出、账号停用、令牌轮换或权限撤销按策略失效；多标签页一致；浏览器关闭后的持久记住登录为单独可配置策略。
  验收：AC-SE-02
- [x] T-SE-03 · 安全会话传输和CSRF防护 · P0 · 依赖：SE-01
  交付：浏览器端不保存可读的长期认证令牌；会话标识采用受保护cookie/等效方案，生产HTTPS及HttpOnly/SameSite策略可验证；cookie鉴权写操作具备CSRF/Origin检查；会话不进URL或日志。
  验收：AC-SE-03
- [x] T-SE-04 · 跨控制节点的会话连续性 · P0 · 依赖：SE-02, SE-03, CP-01
  交付：登录A后请求落到B仍合法；重启/切换控制实例按有效期恢复；集群撤销即时按规定传播，不以粘性会话掩盖状态缺失。
  验收：AC-SE-04
- [x] T-SE-05 · CLI/API兼容及身份冲突规则 · P1 · 依赖：SE-03, CP-05
  交付：既有CLI/API令牌可继续使用；cookie与Authorization身份冲突有明确拒绝/优先规则；会话恢复重验权限，晚到响应不能复活退出会话，双语提示一致。
  验收：AC-SE-05
