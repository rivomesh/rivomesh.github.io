# Build RivoMesh together

<p class="landing-lead">Help improve replication through clear bug reports, reproducible database profiles and understandable documentation.</p>

[Source repository](https://github.com/rivomesh/rivomesh) · [Report an issue](https://github.com/rivomesh/rivomesh/issues) · [Contribute a pull request](https://github.com/rivomesh/rivomesh/pulls)

## Ways to contribute

| Area | Useful contributions |
| --- | --- |
| Documentation | Correct steps, explain terms, review translations and fix links |
| Compatibility | Record exact database mode/version, driver, JDK, workload and reproduction steps |
| Implementation | Fix bugs, improve connectors and recovery workflows, and add relevant tests |
| Usability | Improve the task wizard, error explanations and accessibility |
| Operations | Document install-to-first-sync blockers, outages and recovery behavior |

## A useful issue report

Provide the exact RivoMesh version, database product/version/mode, JDK, deployment and journal profile, reproduction steps, expected behavior and actual behavior. Include redacted configuration and relevant errors. Do not post credentials, management tokens or raw business records.

## Submit an improvement

Small fixes can go directly into a pull request. For new connectors, recovery mechanisms or deployment profiles, open an issue to discuss the use case and scope first. Describe the resulting behavior, testing and compatibility impact, and update the relevant documentation.

Use the [product roadmap](/docs/en/start/roadmap.html) to find existing capabilities and verification priorities. Link any related issue and include the test environment, recovery behavior and migration impact.
