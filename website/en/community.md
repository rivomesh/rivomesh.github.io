# Build RivoMesh together

<p class="landing-lead">Help improve replication through clear bug reports, reproducible database profiles and understandable documentation.</p>

[Source repository](https://github.com/rivomesh/rivomesh) · [Report an issue](https://github.com/rivomesh/rivomesh/issues) · [Contribute a pull request](https://github.com/rivomesh/rivomesh/pulls)

## Ways to contribute

| Area | Useful contributions |
| --- | --- |
| Documentation | Correct steps, explain terms, review translations and fix links |
| Compatibility | Record exact database mode/version, driver, JDK, workload and reproduction steps |
| Implementation | Connect a change to its SDD requirement, design and acceptance conditions |
| Usability | Improve the task wizard, error explanations and accessibility |
| Operations | Document install-to-first-sync blockers, outages and recovery behavior |

## A useful issue report

Provide the exact RivoMesh version, database product/version/mode, JDK, deployment and journal profile, reproduction steps, expected behavior and actual behavior. Include redacted configuration and relevant errors. Do not post credentials, management tokens or raw business records.

Use [the roadmap](/docs/en/start/roadmap.html), [requirements](/docs/en/sdd/spec.html) and [acceptance matrix](/docs/en/sdd/acceptance.html) to discuss scope. A pull request should describe behavior, validation, rejection paths, recovery and migration impact, and update the corresponding Chinese and English documentation.

## License and release status

The checked core source and repository metadata do not provide an explicit project LICENSE. Do not infer Apache licensing from similar projects or from individual dependency licenses. Consult the [core repository](https://github.com/rivomesh/rivomesh) for any subsequently published terms before relying on reuse permissions.

There is no formal Release in the checked baseline. See [source and downloads](/en/download.html) for the current build path. GitHub Issues and pull requests are the available contribution channels; this site does not advertise an unconfigured Discussions board.
