数据库同步是什么
RivoMesh 是一个基于 Java 的数据库实时同步平台。它读取 MySQL 已有的数据和后续变更，把数据送到数据库、分析系统或者消息队列。全量、增量、持久日志和目标确认，共同组成一条同步链路。

准备并创建任务
第一次使用，请准备一个 MySQL 测试源和独立的空目标。从核心源码构建并启动控制台，通过向导填写连接、库映射和日志。数据库管理员需要核对 GTID、完整行镜像，以及复制和快照权限。

检查、启动与观察
保存配置之后，先检查，再启动。控制台提供任务、阶段、积压和目标错误入口。在测试库核对新增、修改、删除和重启恢复。这里使用真实开发预览截图说明界面，画面中的数字不是运行效果承诺。

校验与按计划修复
遇到目标错误，先修复原因，再重试原事务。指定 MySQL 和 PostgreSQL 目标可以在共同校验点进行数据比较，由管理员审阅计划后修复。修复后仍需核对结果并显式恢复，业务切换另有计划。

跟着使用指南完成同步
使用指南按实际操作组织。从安装和登录开始，跟着向导创建任务，再学习查看进度、处理故障和核对数据。中文搜索可以帮你找到具体步骤。连接不同数据库前，请先查看连接说明。建议先完成小规模测试，再逐步扩大使用范围。
